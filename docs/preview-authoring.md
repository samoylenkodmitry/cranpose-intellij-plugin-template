# Preview navigation and unobstructed authoring

The shared Rust host lets source tabs share a running preview workspace after a
`studio.host` navigation request. Each tab keeps its own mounting point. Returning
to a linked tab mounts the same controller and application; closing one tab keeps
the workspace alive while another still uses it. A destination tab's previous
workspace remains owned by that tab and is released when its last owner closes.
No application restart is required for source navigation.

Live controls leave source presses to the editor. IntelliJ's outside-click
cancellation is disabled because it consumes the first click; the editor listener
dismisses the control on mouse press without consuming that event. Popup placement
prefers below or above the source line, then beside it. If there is no safe room,
the control stays hidden instead of covering the source. The renderer is reused.

The authoring catalog groups `Color`, `Color::rgba`, `Color::rgb`,
`Color::from_rgba_u8` and `Color::from_rgb_u8` with literal channels as one color.
Byte edits preserve integer channels, suffixes, comments and numeric base. RGB
constructors are opaque and offer hue, saturation and brightness; RGBA also offers
opacity. Dynamic channels and compiler-owned contexts retain compiler behavior.
Instrumentation stays in the plugin's development copy.

Rust tests compile generated byte-color instrumentation and verify updates. Actual
IDE integration checks shared preview mounts, origin-tab disposal, final disposal,
non-consuming popup presses and callback cleanup. The native inspector fixture
checks full-preview Pick separately from panel visibility and zero snapshot
requests when both controls are off.

## Live recomposition counters

A Studio controller can send `studio.host` messages with `action: "recompositions"`,
the active `session`, and a `rows` array. Each row contains an absolute `file`,
composable `name`, one-based `line`, `recompositions`, and the number of live
`instances`. The controller resolves private-build paths and sums instances of
the same definition before sending the rows.

The host places native block inlays above matching composable definitions in all
open project editors. It updates labels in place and follows document offsets
when source moves. An empty array clears the counters. The workspace rejects
other sessions and clears its inlays when the preview stops, is replaced, loses
its controller connection, or is disposed. The controller should poll while the
preview runs so newly opened editors also receive counters.
